# Лабораторна робота 3

Python-проєкт для роботи 3_lab. Для керування залежностями та запуску команд
використовується Poetry.

## Налаштування

З каталогу `testing/3_lab` встановіть залежності:

```bash
poetry install
```

## Тести

Тести розміщуються в каталозі `tests/`. Запустити їх можна командою:

```bash
poetry run pytest
```


№## Перевірка покриття тестами
після встановлення, виконавча програма `coverage` дозволяє перевірити покриття коду тестами.  і вона є доступною всередиі віртуального середовища, створеного Poetry. Щоб встановити її, виконайте команду:
```bash
poetry add coverage --dev

poetry run coverage run -m unittest discover

poetry run coverage report --skip-empty

```
